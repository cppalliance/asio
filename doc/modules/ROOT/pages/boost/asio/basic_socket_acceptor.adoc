== Description

The basic&lowbar;socket&lowbar;acceptor class template is used for accepting new socket connections&period;

== Thread Safety
_Distinct_ _objects&colon;_ Safe&period; _Shared_ _objects&colon;_ Unsafe&period;

Synchronous `accept` operations are thread safe, if the underlying operating system calls are also thread safe&period; This means that it is permitted to perform concurrent calls to synchronous `accept` operations on a single socket object&period; Other synchronous operations, such as `open` or `close,` are not thread safe&period;

== Example
Opening a socket acceptor with the SO&lowbar;REUSEADDR option enabled&colon;

[,cpp]
----
boost::asio::ip::tcp::acceptor acceptor(my_context);
boost::asio::ip::tcp::endpoint endpoint(boost::asio::ip::tcp::v4(), port);
acceptor.open(endpoint.protocol());
acceptor.set_option(boost::asio::ip::tcp::acceptor::reuse_address(true));
acceptor.bind(endpoint);
acceptor.listen();
----
