Read data into a dynamic buffer sequence until some part of the data it contains matches a regular expression&period;

== Description

This function is used to read data into the specified dynamic buffer sequence until the dynamic buffer sequence&apos;s get area contains some data that matches a regular expression&period; The call will block until one of the following conditions is true&colon;

* A substring of the dynamic buffer sequence&apos;s get area matches the regular expression&period;
* An error occurred&period;

This operation is implemented in terms of zero or more calls to the stream&apos;s read&lowbar;some function&period; If the dynamic buffer sequence&apos;s get area already contains data that matches the regular expression, the function returns immediately&period;

[NOTE]
After a successful read&lowbar;until operation, the dynamic buffer sequence may contain additional data beyond that which matched the regular expression&period; An application will typically leave that data in the dynamic buffer sequence for a subsequent read&lowbar;until operation to examine&period;

== Return Value

The number of bytes in the dynamic buffer sequence&apos;s get area up to and including the substring that matches the regular expression&period; Returns 0 if an error occurred&period;
