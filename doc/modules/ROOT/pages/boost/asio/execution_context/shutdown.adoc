Shuts down all services in the context&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;execution&lowbar;context&period;hpp&gt;`

== Description

This function is implemented as follows&colon;

* For each service object `svc` in the execution&lowbar;context set, in reverse order of the beginning of service object lifetime, performs `svc&hyphen;&gt;shutdown()&period;`
