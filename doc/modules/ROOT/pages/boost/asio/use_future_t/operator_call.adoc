== Description

The `package` function is used to adapt a function object as a packaged task&period; When this adapter is passed as a completion token to an asynchronous operation, the result of the function object is returned via a std&colon;&colon;future&period;

== Example
[,cpp]
----
std::future<std::size_t> fut =
  my_socket.async_read_some(buffer,
    use_future([](boost::system::error_code ec, std::size_t n)
      {
        return ec ? 0 : n;
      }));
...
std::size_t n = fut.get(); 
----
