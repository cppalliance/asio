== Description

The detached&lowbar;t class is used to indicate that an asynchronous operation is detached&period; That is, there is no completion handler waiting for the operation&apos;s result&period; A detached&lowbar;t object may be passed as a handler to an asynchronous operation, typically using the special value `boost&colon;&colon;asio&colon;&colon;detached&period;` For example&colon;

[,cpp]
----
my_socket.async_send(my_buffer, boost::asio::detached);
----
