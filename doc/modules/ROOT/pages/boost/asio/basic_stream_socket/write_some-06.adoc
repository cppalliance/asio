== Description

This function is used to write data to the stream socket&period; The function call will block until one or more bytes of the data has been written successfully, or until an error occurs&period;

[NOTE]
The write&lowbar;some operation may not transmit all of the data to the peer&period; Consider using the xref:boost/asio/write-02d.adoc[`write`] function if you need to ensure that all data is written before the blocking operation completes&period;

== Return Value

The number of bytes written&period; Returns 0 if an error occurred&period;
