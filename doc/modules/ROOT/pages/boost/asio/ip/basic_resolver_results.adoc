== Description

The boost&colon;&colon;asio&colon;&colon;ip&colon;&colon;basic&lowbar;resolver&lowbar;results class template is used to define a range over the results returned by a resolver&period;

The iterator&apos;s value&lowbar;type, obtained when a results iterator is dereferenced, is&colon;

[,cpp]
----
const basic_resolver_entry<InternetProtocol> 
----
[NOTE]
For backward compatibility, basic&lowbar;resolver&lowbar;results is derived from basic&lowbar;resolver&lowbar;iterator&period; This derivation is deprecated&period;
