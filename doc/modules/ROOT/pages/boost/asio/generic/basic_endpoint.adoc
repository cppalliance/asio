== Description

The boost&colon;&colon;asio&colon;&colon;generic&colon;&colon;basic&lowbar;endpoint class template describes an endpoint that may be associated with any socket type&period;

[NOTE]
The socket types sockaddr type must be able to fit into a `sockaddr&lowbar;storage` structure&period;
