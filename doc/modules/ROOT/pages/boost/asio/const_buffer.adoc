== Description

The const&lowbar;buffer class provides a safe representation of a buffer that cannot be modified&period; It does not own the underlying data, and so is cheap to copy or assign&period;

== Accessing Buffer Contents
The contents of a buffer may be accessed using the `data()` and `size()` member functions&colon;

[,cpp]
----
boost::asio::const_buffer b1 = ...;
std::size_t s1 = b1.size();
const unsigned char* p1 = static_cast<const unsigned char*>(b1.data());
----
The `data()` member function permits violations of type safety, so uses of it in application code should be carefully considered&period;
