== Description

This function is used to ask the executor to execute the given function object&period; The function object is executed according to the rules of the target executor object&period;

[,cpp]
----
void function(); 
----
== Parameters

[cols=2]
|===
| Name
| Description
| *f*
| The function object to be called&period; The executor will make a copy of the handler object as required&period; The function signature of the function object must be&colon;
| *a*
