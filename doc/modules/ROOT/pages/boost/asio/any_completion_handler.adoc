== Description

The `any&lowbar;completion&lowbar;handler` class template is a polymorphic wrapper for completion handlers that propagates the associated executor, associated allocator, and associated cancellation slot through a type&hyphen;erasing interface&period;

When using `any&lowbar;completion&lowbar;handler,` specify one or more completion signatures as template parameters&period; These will dictate the arguments that may be passed to the handler through the polymorphic interface&period;

Typical uses for `any&lowbar;completion&lowbar;handler` include&colon;

* Separate compilation of asynchronous operation implementations&period;
* Enabling interoperability between asynchronous operations and virtual functions&period;
