== Description

This function is used to write data to the random&hyphen;access handle&period; The function call will block until one or more bytes of the data has been written successfully, or until an error occurs&period;

[NOTE]
The write&lowbar;some&lowbar;at operation may not write all of the data&period; Consider using the xref:boost/asio/write_at-05c.adoc[`write&lowbar;at`] function if you need to ensure that all data is written before the blocking operation completes&period;

== Example
To write a single data buffer use the xref:boost/asio/buffer-068.adoc[`buffer`] function as follows&colon;

[,cpp]
----
handle.write_some_at(42, boost::asio::buffer(data, size));
----
See the xref:boost/asio/buffer-068.adoc[`buffer`] documentation for information on writing multiple buffers in one go, and how to use it with arrays, boost&colon;&colon;array or std&colon;&colon;vector&period;
