== Description

This function returns a reference to the lowest layer in a stack of layers&period; Since an overlapped&lowbar;handle cannot contain any further layers, it simply returns a reference to itself&period;

== Return Value

A reference to the lowest layer in the stack of layers&period; Ownership is not transferred to the caller&period;
