== Description

The deferred&lowbar;t class is used to indicate that an asynchronous operation should return a function object which is itself an initiation function&period; A deferred&lowbar;t object may be passed as a completion token to an asynchronous operation, typically as the default completion token&colon;

[,cpp]
----
auto my_deferred_op = my_socket.async_read_some(my_buffer); 
----
or by explicitly passing the special value `boost&colon;&colon;asio&colon;&colon;deferred&colon;`

[,cpp]
----
auto my_deferred_op
  = my_socket.async_read_some(my_buffer,
      boost::asio::deferred); 
----
The initiating function (async&lowbar;read&lowbar;some in the above example) returns a function object that will lazily initiate the operation&period;
