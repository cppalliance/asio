Read data into a streambuf until some part of the data it contains matches a regular expression&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;read&lowbar;until&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
template&lt;
    typename SyncReadStream,
    typename Allocator,
    typename Traits&gt;
size&lowbar;t
read&lowbar;until(
    SyncReadStream& s,
    xref:boost/asio/basic_streambuf.adoc[boost::asio::basic&lowbar;streambuf&lt;Allocator&gt;]& b,
    boost::basic&lowbar;regex&lt;char, Traits&gt; const& expr);
----

== Description

This function is used to read data into the specified streambuf until the streambuf&apos;s get area contains some data that matches a regular expression&period; The call will block until one of the following conditions is true&colon;

* A substring of the streambuf&apos;s get area matches the regular expression&period;
* An error occurred&period;

This operation is implemented in terms of zero or more calls to the stream&apos;s read&lowbar;some function&period; If the streambuf&apos;s get area already contains data that matches the regular expression, the function returns immediately&period;

[NOTE]
After a successful read&lowbar;until operation, the streambuf may contain additional data beyond that which matched the regular expression&period; An application will typically leave that data in the streambuf for a subsequent read&lowbar;until operation to examine&period;

== Example
To read data into a streambuf until a CR&hyphen;LF sequence is encountered&colon;

[,cpp]
----
boost::asio::streambuf b;
boost::asio::read_until(s, b, boost::regex("\r\n"));
std::istream is(&b);
std::string line;
std::getline(is, line); 
----
After the `read&lowbar;until` operation completes successfully, the buffer `b` contains the data which matched the regular expression&colon;

[,cpp]
----
{ 'a', 'b', ..., 'c', '\r', '\n', 'd', 'e', ... } 
----
The call to `std&colon;&colon;getline` then extracts the data up to and including the newline (which is discarded), so that the string `line` contains&colon;

[,cpp]
----
{ 'a', 'b', ..., 'c', '\r' } 
----
The remaining data is left in the buffer `b` as follows&colon;

[,cpp]
----
{ 'd', 'e', ... } 
----
This data may be the start of a new line, to be extracted by a subsequent `read&lowbar;until` operation&period;
