== Description

The thread pool class is an execution context where functions are permitted to run on one of a fixed number of threads&period;

== Thread Safety
_Distinct_ _objects&colon;_ Safe&period; _Shared_ _objects&colon;_ Safe, with the specific exceptions of the join() wait() and notify&lowbar;fork() functions&period; The join() and wait() functions must not be called at the same time as other calls to join() or wait() on the same pool&period; The notify&lowbar;fork() function should not be called while any thread&lowbar;pool function, or any function on an I&sol;O object that is associated with the thread&lowbar;pool, is being called in another thread&period; (In effect, this means that notify&lowbar;fork() is safe only on a thread pool that has no internal or attached threads at the time&period;)

== Submitting tasks to the pool
To submit functions to the thread pool, use the xref:boost/asio/dispatch-09.adoc[`boost&colon;&colon;asio&colon;&colon;dispatch`], xref:boost/asio/post-055.adoc[`boost&colon;&colon;asio&colon;&colon;post`] or xref:boost/asio/defer-0c2.adoc[`boost&colon;&colon;asio&colon;&colon;defer`] free functions&period;

For example&colon;

[,cpp]
----
void my_task()
{
  ...
}

...

// Launch the pool with four threads.
boost::asio::thread_pool pool(4);

// Submit a function to the pool.
boost::asio::post(pool, my_task);

// Submit a lambda object to the pool.
boost::asio::post(pool,
    []()
    {
      ...
    });

// Wait for all tasks in the pool to complete.
pool.join(); 
----
