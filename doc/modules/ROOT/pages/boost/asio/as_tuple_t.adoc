== Description

The as&lowbar;tuple&lowbar;t class is used to indicate that any arguments to the completion handler should be combined and passed as a single tuple argument&period; The arguments are first moved into a `std&colon;&colon;tuple` and that tuple is then passed to the completion handler&period;
