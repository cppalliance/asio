== Description

Asynchronous operations may represent a continuation of the asynchronous control flow associated with the current handler&period; The implementation can use this knowledge to optimise scheduling of the handler&period;

Implement asio&lowbar;handler&lowbar;is&lowbar;continuation for your own handlers to indicate when a handler represents a continuation&period;

The default implementation of the continuation hook returns &period;
