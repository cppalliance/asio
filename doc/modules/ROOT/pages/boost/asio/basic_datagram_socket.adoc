== Description

The basic&lowbar;datagram&lowbar;socket class template provides asynchronous and blocking datagram&hyphen;oriented socket functionality&period;

== Thread Safety
_Distinct_ _objects&colon;_ Safe&period; _Shared_ _objects&colon;_ Unsafe&period;

Synchronous `send,` `send&lowbar;to,` `receive,` `receive&lowbar;from,` `connect,` and `shutdown` operations are thread safe with respect to each other, if the underlying operating system calls are also thread safe&period; This means that it is permitted to perform concurrent calls to these synchronous operations on a single socket object&period; Other synchronous operations, such as `open` or `close,` are not thread safe&period;
