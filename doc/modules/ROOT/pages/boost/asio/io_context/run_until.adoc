Run the io&lowbar;context object&apos;s event processing loop until a specified time&period;

== Synopsis

== Description

The run&lowbar;until() function blocks until all work has finished and there are no more handlers to be dispatched, until the io&lowbar;context has been stopped, or until the specified time has been reached&period;

== Return Value

The number of handlers that were executed&period;
