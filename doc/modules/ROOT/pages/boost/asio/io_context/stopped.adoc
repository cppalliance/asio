== Description

This function is used to determine whether an io&lowbar;context object has been stopped, either through an explicit call to stop(), or due to running out of work&period; When an io&lowbar;context object is stopped, calls to run(), run&lowbar;one(), poll() or poll&lowbar;one() will return immediately without invoking any handlers&period;

== Return Value

`true` if the io&lowbar;context object is stopped, otherwise `false&period;`
