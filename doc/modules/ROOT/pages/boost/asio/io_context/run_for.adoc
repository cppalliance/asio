Run the io&lowbar;context object&apos;s event processing loop for a specified duration&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;io&lowbar;context&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
template&lt;
    typename Rep,
    typename Period&gt;
size&lowbar;t
run&lowbar;for(chrono::duration&lt;Rep, Period&gt; const& rel&lowbar;time);
----

== Description

The run&lowbar;for() function blocks until all work has finished and there are no more handlers to be dispatched, until the io&lowbar;context has been stopped, or until the specified duration has elapsed&period;

== Return Value

The number of handlers that were executed&period;
