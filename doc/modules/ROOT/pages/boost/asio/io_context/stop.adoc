== Description

This function does not block, but instead simply signals the io&lowbar;context to stop&period; All invocations of its run() or run&lowbar;one() member functions should return as soon as possible&period; Subsequent calls to run(), run&lowbar;one(), poll() or poll&lowbar;one() will return immediately until restart() is called&period;
