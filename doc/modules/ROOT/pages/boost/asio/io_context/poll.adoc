Run the io&lowbar;context object&apos;s event processing loop to execute ready handlers&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;io&lowbar;context&period;hpp&gt;`

== Description

The poll() function runs handlers that are ready to run, without blocking, until the io&lowbar;context has been stopped or there are no more ready handlers&period;

== Return Value

The number of handlers that were executed&period;
