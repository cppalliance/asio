Close the file&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;basic&lowbar;file&period;hpp&gt;`

boost::system::error&lowbar;code

== Description

This function is used to close the file&period; Any asynchronous read or write operations will be cancelled immediately, and will complete with the boost&colon;&colon;asio&colon;&colon;error&colon;&colon;operation&lowbar;aborted error&period;

== Example
[,cpp]
----
boost::asio::stream_file file(my_context);
...
boost::system::error_code ec;
file.close(ec);
if (ec)
{
  // An error occurred.
}
----
== Parameters

[cols=2]
|===
| Name
| Description
| *ec*
| Set to indicate what error occurred, if any&period; Note that, even if the function indicates an error, the underlying descriptor is closed&period;
|===
