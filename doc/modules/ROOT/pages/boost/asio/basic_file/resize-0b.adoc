Alter the size of the file&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;basic&lowbar;file&period;hpp&gt;`

== Description

This function resizes the file to the specified size, in bytes&period; If the current file size exceeds `n` then any extra data is discarded&period; If the current size is less than `n` then the file is extended and filled with zeroes&period;

== Parameters

[cols=2]
|===
| Name
| Description
| *n*
| The new size for the file&period;
| *ec*
| Set to indicate what error occurred, if any&period;
|===
