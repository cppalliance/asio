== Description

*DynamicBuffer&lowbar;v1&colon;* Removes `n` characters from the beginning of the input sequence&period;

[NOTE]
If `n` is greater than the size of the input sequence, the entire input sequence is consumed and no error is issued&period;

*DynamicBuffer&lowbar;v2&colon;* Erases `n` bytes from the beginning of the string&period; If `n` is greater than the current size of the string, the string is emptied&period;
