== Description

This function is used to close the acceptor&period; Any asynchronous accept operations will be cancelled immediately&period;

A subsequent call to open() is required before the acceptor can again be used to again perform socket accept operations&period;

== Example
[,cpp]
----
boost::asio::ip::tcp::acceptor acceptor(my_context);
...
boost::system::error_code ec;
acceptor.close(ec);
if (ec)
{
  // An error occurred.
}
----
