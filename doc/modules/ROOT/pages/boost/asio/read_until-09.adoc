Read data into a streambuf until a function object indicates a match&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;read&lowbar;until&period;hpp&gt;`

== Description

This function is used to read data into the specified streambuf until a user&hyphen;defined match condition function object, when applied to the data contained in the streambuf, indicates a successful match&period; The call will block until one of the following conditions is true&colon;

* The match condition function object returns a std&colon;&colon;pair where the second element evaluates to true&period;
* An error occurred&period;

This operation is implemented in terms of zero or more calls to the stream&apos;s read&lowbar;some function&period; If the match condition function object already indicates a match, the function returns immediately&period;

[,cpp]
----
pair<iterator, bool> match_condition(iterator begin, iterator end);
----
where `iterator` represents the type&colon;

[,cpp]
----
buffers_iterator<basic_streambuf<Allocator>::const_buffers_type>
----
The iterator parameters `begin` and `end` define the range of bytes to be scanned to determine whether there is a match&period; The `first` member of the return value is an iterator marking one&hyphen;past&hyphen;the&hyphen;end of the bytes that have been consumed by the match function&period; This iterator is used to calculate the `begin` parameter for any subsequent invocation of the match condition&period; The `second` member of the return value is true if a match has been found, false otherwise&period;

[NOTE]
After a successful read&lowbar;until operation, the streambuf may contain additional data beyond that which matched the function object&period; An application will typically leave that data in the streambuf for a subsequent read&lowbar;until operation to examine&period;

[NOTE]
The default implementation of the `is&lowbar;match&lowbar;condition` type trait evaluates to true for function pointers and function objects with a `result&lowbar;type` typedef&period; It must be specialised for other user&hyphen;defined function objects&period;

== Examples
To read data into a streambuf until whitespace is encountered&colon;

[,cpp]
----
typedef boost::asio::buffers_iterator<
    boost::asio::streambuf::const_buffers_type> iterator;

std::pair<iterator, bool>
match_whitespace(iterator begin, iterator end)
{
  iterator i = begin;
  while (i != end)
    if (std::isspace(*i++))
      return std::make_pair(i, true);
  return std::make_pair(i, false);
}
...
boost::asio::streambuf b;
boost::asio::read_until(s, b, match_whitespace);
----
To read data into a streambuf until a matching character is found&colon;

[,cpp]
----
class match_char
{
public:
  explicit match_char(char c) : c_(c) {}

  template <typename Iterator>
  std::pair<Iterator, bool> operator()(
      Iterator begin, Iterator end) const
  {
    Iterator i = begin;
    while (i != end)
      if (c_ == *i++)
        return std::make_pair(i, true);
    return std::make_pair(i, false);
  }

private:
  char c_;
};

namespace asio {
  template <> struct is_match_condition<match_char>
    : public boost::true_type {};
} // namespace asio
...
boost::asio::streambuf b;
boost::asio::read_until(s, b, match_char('a'));
----
