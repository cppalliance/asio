== Description

The basic&lowbar;random&lowbar;access&lowbar;file class template provides asynchronous and blocking random&hyphen;access file functionality&period;

== Thread Safety
_Distinct_ _objects&colon;_ Safe&period; _Shared_ _objects&colon;_ Unsafe&period;

Synchronous `read&lowbar;some&lowbar;at` and `write&lowbar;some&lowbar;at` operations are thread safe with respect to each other, if the underlying operating system calls are also thread safe&period; This means that it is permitted to perform concurrent calls to these synchronous operations on a single file object&period; Other synchronous operations, such as `open` or `close,` are not thread safe&period;
