Move characters from the output sequence to the input sequence&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;basic&lowbar;streambuf&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
void
commit(size&lowbar;t n);
----

== Description

Appends `n` characters from the start of the output sequence to the input sequence&period; The beginning of the output sequence is advanced by `n` characters&period;

Requires a preceding call where , and no intervening operations that modify the input or output sequence&period;

[NOTE]
If `n` is greater than the size of the output sequence, the entire output sequence is moved to the input sequence and no error is issued&period;
