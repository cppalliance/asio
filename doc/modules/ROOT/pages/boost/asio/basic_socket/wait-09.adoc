Wait for the socket to become ready to read, ready to write, or to have pending error conditions&period;

== Synopsis

== Description

This function is used to perform a blocking wait for a socket to enter a ready to read, write or error condition state&period;

== Example
Waiting for a socket to become readable&period;

[,cpp]
----
boost::asio::ip::tcp::socket socket(my_context);
...
boost::system::error_code ec;
socket.wait(boost::asio::ip::tcp::socket::wait_read, ec);
----
