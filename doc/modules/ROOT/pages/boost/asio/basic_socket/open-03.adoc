Open the socket using the specified protocol&period;

== Synopsis

Declared in `&lt;boost&sol;asio&sol;basic&lowbar;socket&period;hpp&gt;`

    xref:boost/asio/basic_socket/protocol_type.adoc[protocol&lowbar;type] const& protocol,

== Description

This function opens the socket so that it will use the specified protocol&period;

== Example
[,cpp]
----
boost::asio::ip::tcp::socket socket(my_context);
boost::system::error_code ec;
socket.open(boost::asio::ip::tcp::v4(), ec);
if (ec)
{
  // An error occurred.
}
----
