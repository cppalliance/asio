Bind the socket to the given local endpoint&period;

== Synopsis

== Description

This function binds the socket to the specified endpoint on the local machine&period;

== Example
[,cpp]
----
boost::asio::ip::tcp::socket socket(my_context);
socket.open(boost::asio::ip::tcp::v4());
socket.bind(boost::asio::ip::tcp::endpoint(
      boost::asio::ip::tcp::v4(), 12345));
----
